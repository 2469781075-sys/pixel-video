# 《窗》第三版对照：掌机像素角色、固定镜头

保留用户认可的第二版，其文件全部不变；本版在独立的 `sample-v3/` 中制作。

人物参考宝可梦经典掌机游戏的角色设计语言：清晰的像素轮廓、整洁发束、较紧凑的少年比例和简洁分色。仍是棕发、青绿校服、托腮望窗的原创学生。背景直接复用第二版的暖木色教室、窗光与绣球花。

本版全程固定机位：移除镜头推拉、平移和人物上下跳动；用低频眨眼、少量细雨与微粒、缓慢色温变化表现情绪。24 秒、1280×720、16 fps；字幕和音频保留第二版方案，没有旁白。

这是人物美术和镜头稳定性的对照小样，完整推窗表演尚未制作。

## 复现

从仓库根目录运行 `python3 sample-v3/render.py`。依赖见 `sample-v3/requirements.txt`，系统需有 FFmpeg 与 Noto CJK 字体。角色图层在本版 `assets/` 中；背景在 `sample-v2/assets/background.png`，请保留两版目录结构。

交付：`window-still.mp4`、`poster.png`、`storyboard.png` 和图层、生成脚本。
