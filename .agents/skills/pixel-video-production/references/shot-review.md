# 分镜与坐姿复核

本规则来自用户对《窗》第二版的具体反馈：新增镜头大量复用旧图裁切，主角坐姿和桌椅遮挡不正确。旧版编码、字幕和音频通过检查，不等于美术和叙事通过。第二版暂作为问题对照，不作为座位结构的正确模板。

## 新分镜的依据

- 每个镜头写清原文句子、画面新增的信息、角色状态、动作和所需素材。增加镜头数不能代替这些内容。
- 同一张图的放大、缩小或裁切不算新绘制的分镜。仅变大但没有叙事信息的切换删除；需要新视角时绘制独立构图。
- 复用角色设计和教室平面布局；变化来自角色的真实动作、独立构图、明确的场景和心理状态。回到先前构图可以表达“仍跑不出教室”，但要说明这个叙事用途。
- 真正的细节镜头可以表达窗扣、指尖或轨道动作，需专门绘制并保持空间关系，不能把全景裁切后当作已经完成细节设计。
- 先核对新原画，再做局部动画。单镜头固定相机；字幕用完整原文和实际曼波时间轴，继续使用大字号。

## 人物、桌子和椅子的关系

1. 先确定教室平面关系：前墙是黑板和一层高台，左墙是水平推拉窗，每组是两张并桌、两把椅子、两名同桌。主角在该组靠窗的一侧。
2. 对每个新视角明确“前方”和“靠窗”在画面中的投影。反向或侧面拍摄时不能把窗墙搬到同桌一侧来维持旧构图。
3. 至少用一张全身侧面检查图看清椅背在背后、臀部在椅座上、大腿向桌下伸、膝盖弯曲、小腿与脚接地。课桌在人物前面，椅子支撑身体，不额外放一把空椅挡在桌前。
4. 两张并桌的缝隙分隔左右桌面，不从主角身体中间穿过；主角不能站或坐在两排桌子之间充当“座位”。
5. 按实际前后位置检查遮挡：桌面可遮住部分大腿，椅背在背后，脚在自己的桌下。头、身体、腿和脚属于同一个坐姿方向；转头不需要翻转腰部。
6. 背景同学同样逐个查看支撑与关节，尤其第二路最后一排。少量像素不动只证明该区域没有动画位移，不能证明人体正确。

## 复核记录

记录实际查看的图片、尚未解决的问题和该图的用途。将“结构检查图”“候选分镜”“正式素材”和“成片”区别写清，不把生成成功、帧数增加、裁切比例正确或程序检查通过写成美术通过。用户提出的新缺陷更新到项目约束，不继续使用缺陷图作为结构参考。
