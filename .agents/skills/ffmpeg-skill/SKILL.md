# FFmpeg 工具集 · 项目适配

来源是 `kajisho5/ffmpeg-skill`，固定版本及校验值在 `../sources.lock.json`。完整工具指南保存在 [UPSTREAM-SKILL.md](UPSTREAM-SKILL.md)，脚本使用 Python 标准库和本机 FFmpeg/ffprobe。

开始执行媒体处理前读取原始指南，按任务使用 `scripts/<工具>.py --help` 确认参数。常用入口：

- `probe.py`：读取实际声画时长、帧率、尺寸、编码和音轨信息。
- `look.py`：从实际编码视频导出代表帧或联系表，再用图片查看工具检查。
- `audio.py`、`loudness.py`：替换或混合已有曼波音轨、控制背景声和响度。
- `caption.py`：使用已经逐字确认的 SRT/ASS 文案，检查中文字体与排版。
- `join.py`、`sequence.py`、`export.py`：拼接、帧序列编码及指定格式导出。
- `check.py`：检查明确指定的平台规格；未指定平台时验证实际 MP4 规格。

保留源文件，输出到本次作品的新路径。长编码先用 `--dry-run --json` 检查计划，再执行；执行成功后核对实际输出，完整解码并查看代表帧。上游的尺寸、内容、响度等建议需要按用户目标判断，不能为了消除检查提示裁掉画面或原文。

本项目默认按已确认的横屏像素短片交付 MP4、原文 SRT 和曼波音轨，不重复询问已经明确的尺寸、声音或交付形式。逐句原文字幕来自实际合成的时间轴，不用识别结果替换原文；不自动删除停顿、加速朗读、裁切为竖屏或给背景加镜头运动。

仅在用户要求对应新能力时使用其他脚本；本次已验证 `probe.py` 和 `look.py`，没有声称所有可选工具均已测试。自动探测或测量结果不等于画面审美、发音或故事节奏已被用户认可。最终报告优先遵循当前对话的语言和格式要求。
