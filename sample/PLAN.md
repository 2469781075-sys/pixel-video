# 《窗》像素动画小样

根据用户原文制作，暂定名称《窗》。主题是拥挤、疏离，以及开窗带来的短暂自由；结尾保持原文的困境，不添加走出教室的圆满结局。

## 完整片规划
建议时长 90–120 秒，横屏 16:9，320×180 像素画面整数倍放大。

1. 教室 / 0–20 秒：由整齐桌椅构成近似铁轨的透视线，讲台压在画面前方，建立拥挤感。
2. 边界 / 20–45 秒：同学交谈的动作形成几个局部循环，主人公独坐左窗边。声音逐渐模糊，窗外雨声显现。
3. 开窗 / 45–70 秒：手停在窗扣，迟疑后打开。玻璃移动，风与湿冷的光跨过桌椅，颜色从灰蓝转为青绿。
4. 想象 / 70–95 秒：风化作河流，简短映出骑士的剪影。采用象征表达，不直接展示对同学的性化描述。
5. 留下 / 95–120 秒：想象退去，构图回到窗边。夜色替代白昼，主人公仍在座位上，保留一束微光。

## 本次小样
20 秒、12 fps、960×540 MP4，无音轨。四段摘句字幕配桌椅、人群、推窗、风与入夜的动态。人物是简化像素占位造型，用于确认叙事与色彩；完整片需细化角色动作、推窗特写与声音设计。

运行：`python3 sample/render.py`（从仓库根目录）。依赖 Pillow、FFmpeg 与系统 Noto CJK 字体。生成 window.mp4、storyboard.png 和 poster.png。
