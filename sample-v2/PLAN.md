# 《窗》第二版：可爱、精细的像素动画

本版以用户要求的「可爱一些、精致一些」重做美术：奶油与薄荷配色，暖木色教室，圆润的大头小人物，细化窗景、植物、书本、校服与书包。保留原文孤独与短暂自由的情绪。

24 秒风格小样，横屏。用独立背景和透明角色图层合成，包含角色呼吸、雨滴、风中微粒、缓慢镜头运动与逐步入夜。配合成轻雨、风与稀疏音符；没有旁白。推窗的完整逐帧表演尚未制作，这版优先确认美术与情绪。

字幕摘句来自用户原文；第一句关于窗边的位置、第二句关于梦想、第三句关于清澈的凉、最后一句关于仍在教室。字幕为分镜长度作了节选。

## 复现

从仓库根目录运行 `python3 sample-v2/render.py`。需要 Python 3、Pillow、NumPy、FFmpeg，以及系统 Noto CJK 字体。

美术图层存放在 `sample-v2/assets/`，由图像生成工具生成。脚本仅负责图层合成、动画、字幕和原创合成音频，不需要再次调用图像服务。

最终交付 `window-cute.mp4`、`poster.png`、`storyboard.png`。第一版 `sample/` 保留用于比较。
