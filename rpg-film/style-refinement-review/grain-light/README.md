# 轻颗粒试稿

在上一轮两张画风调整图上，用内置 image_gen 增加少量材质颗粒，供用户对照检查。当前仍为静态图片，原有 16 张分镜、两张画风试稿和视频文件均保留。

颗粒以低对比的像素纹理为主，集中在地板、柜门、墙面、石头和部分草木上。人物面部与大字幕保持清楚，河面继续使用成组的蓝色色块。这是美术试稿，纹理密度与像素网格不作精确数值保证；正式动画采用时应把这些纹理固定在材质上，避免逐帧随机噪点闪烁。
