# 两张画风调整试稿

本轮只调整教室全景与「河流边界」两张，供用户对照检查；原来的 16 张完整静态分镜与所有视频文件继续保留，没有替换其他画面。

通过内置 image_gen 编辑，重点为哑光地板、收紧明暗层次、整理头发/树叶/水面的像素色块，减少碎纹理和过亮反光。保持对应构图、人物位置与原文大字幕，当前仍为静态图。
