# 全文逐句朗读 · 曼波声线

配音方向已确定为曼波声线朗读原文。

- `original.txt` 保存用户原文，包括原有的标点和省略号。
- `sentences.json` 按句整理全文。尚无实际配音，因此时间戳留空；拿到配音后按实际音频逐句填写。
- 字幕逐字采用原文，允许为屏幕排版换行。全片时长随全文配音确定，先前的 90 秒摘句规划需要重新计算。

同时落实三项画面要求：交谈学生补齐身体和腿，建立坐姿/站姿与桌椅的正确遮挡及地面接触；窗户按统一墙面透视重做，使窗框、窗台与窗外景色自然一致；保持掌机 RPG 风格与稳定机位。

当前已整理朗读文本，尚未生成曼波配音。此环境没有可直接调用的该声线语音服务。下一步需要一个可用的曼波配音工具/服务入口，或已经生成的全文曼波朗读音频。已有音频可以直接用于字幕对齐和视频合成。
